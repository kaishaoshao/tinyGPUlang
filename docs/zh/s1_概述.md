# 概述

本教程演示了如何从LLVM IR生成PTX文件

## 编译器架构

编译器包含3个组件：

- 解析器：读取tgl文件并生成内部抽象语法树
- AST: 抽象语法树的实现
- 代码生成器：从AST对象生成LLVM IR， 它还可以将LLVM IR转换为PTX

所有组件将在本教程后续章节中讨论。

## 如何使用编译器

编译器是一个名为 `tglc` 的可执行文件，带有命令行选项。

使用示例(例如在Windows上)

```
tglc.exe --src tgl_code_file_path.tgl
```

将在同一个文件夹下创建同名但拓展名为.ptx 的PTX文件。

```
tglc.exe --src tgl_code_file_path.tgl --save-temps
```

除了生成PTX之外，它还将输出包括LLVMIR的.ll文件和包含AST打印内容的.ast文件。这有助于更好地理解每一步发生的情况。

```
tglc.exe --src tgl_code_file_path.tgl --out output_folder_path
```

可以指定输出文件夹来保存创建的文件

```
tglc.exe --src tgl_code_file_path.tgl --sm 80
```

将目标架构设置为sm_80。

在Linux上的用法非常相似(在build/tinyGPUlang目录下)：

```
./tglc --version
```

## 测试PTX

`test`文件夹包含一个使用CUDA驱动API执行PTX的示例。

需要相应地更改核函数名称(Kernel name)和PTX文件名。

测试程序没有命令行选项。
