
# 构建 TinyGPUlang 指南

以下为两个已验证支持编译器的平台构建说明：

• **Windows 11**
• **Linux (Ubuntu 24)**

---

## 编译器依赖项

• **LLVM** (需包含头文件和库文件)，测试版本：llvm-18.1.7
• **CUDA**，测试版本：v12.0
  (CUDA 安装不在本教程范围内)

---

## Linux 系统构建指南

### 步骤 1：构建 LLVM

若已安装 LLVM 可跳过此步骤。以下操作在全新 AWS EC2 实例 (Ubuntu 24) 中完成：

#### 1.1 安装必备工具

```bash
sudo apt install clang     # 安装 C/C++ 编译器
sudo apt install cmake    # 安装构建工具
sudo apt install ninja-build  # 安装高效构建系统
```

#### 1.2 下载并解压 LLVM 源码

```bash
wget https://github.com/llvm/llvm-project/archive/refs/tags/llvmorg-18.1.7.tar.gz
tar -xf llvmorg-18.1.7.tar.gz
cd llvm-project-llvmorg-18.1.7/llvm
```

#### 1.3 配置与构建

```bash
mkdir build && cd build
cmake -G Ninja -DLLVM_HOST_TRIPLE=x86_64 -DCMAKE_BUILD_TYPE=Release -S ..
cmake --build .  # 完整构建约需1小时以上
```

#### 1.4 安装 LLVM

```bash
sudo cmake --install .  # 需管理员权限
```

### 步骤 2：构建 TinyGPUlang

#### 2.1 配置项目

```bash
mkdir build && cd build
cmake -G Ninja -DCMAKE_BUILD_TYPE=Release -S ..
```

#### 2.2 执行构建

```bash
cmake --build .
```

## Windows 系统构建指南

### 步骤 1：构建 LLVM

需提前安装 MSVC 及 C++ 开发工具链。建议使用 MSVC 避免系统库兼容性问题。

#### 1.1 下载并解压源码

从 [LLVM 官方仓库](https://github.com/llvm/llvm-project/archive/refs/tags/llvmorg-18.1.7.zip) 下载 ZIP 包，解压后进入 `llvm` 目录。

#### 1.2 生成 Visual Studio 工程

```powershell
mkdir build && cd build
cmake -G "Visual Studio 17 2022" -DLLVM_HOST_TRIPLE=x86_64 -S ..
```

#### 1.3 执行构建

```powershell
cmake --build . --config Release  # 耗时约1小时以上
```

#### 1.4 安装 LLVM

```powershell
cmake --install .  # 需以管理员身份运行
```

### 步骤 2：构建 TinyGPUlang

#### 2.1 配置项目

```powershell
mkdir build && cd build
cmake -G "Visual Studio 17 2022" -S ..
```

#### 2.2 执行构建

```powershell
cmake --build . --config Release
```

---

### 关键参数说明

| 参数                           | 作用描述                    |
| ------------------------------ | --------------------------- |
| `-G Ninja`                   | 指定使用 Ninja 高速构建系统 |
| `-DCMAKE_BUILD_TYPE=Release` | 启用发布模式优化            |
| `-DLLVM_HOST_TRIPLE=x86_64`  | 指定目标平台为 x86_64 架构  |

> **提示**：Windows 用户若遇路径权限问题，建议在 **管理员模式 PowerShell** 中执行安装命令。
